肾移植候选者的再评估（Reassessment） 文献总结（1998-2026）

检索日期：2026-10-12
检索轨道：PubMed（16+10 条检索式，206+61 命中去重，130+60 条相关）+ Tavily 中文通道（KDIGO 候选者评估指南、中国儿童等待者评估指南、肾脏移植长期健康管理指南、UpToDate 候选者/老年候选者评估）
证据分层：国际指南（KDIGO）> 多中心前瞻性/登记处（高）> 单中心队列/综述（中）> 病例（低）

核心结论（先抛）：”候选者再评估”是贯穿等待名单全程 + 移植前最终关口的持续流程，不是入名单时一次性的静态评估。核心框架：① 等待名单动态管理（激活/暂停/失格 delisting）② 移植前最终再评估（癌、心血管、衰弱、感染、依从性、心理社会 6 大维度）③ 等待名单失格（delisting）是既定的临床终点而非失败。三大 2025-2026 前沿：主动 delisting 策略（40484353 多中心前瞻性）、等待名单死亡指标与 delisting 关联（41720194）、衰弱/肌少化作为再评估变量（34656960/32512039）。

一、候选者再评估的框架（不是”一次评估”）

阶段 核心动作 证据
入名单前评估 完整医学 + 心理社会 + 依从性 + 经济/医保 21175834（成人候选者评估经典）/ 11011632（评估潜在受者）
等待名单动态再评估 定期激活/暂停/失格（inactivation/reactivation） 22663992（临时失格：原因/危险因素/结局） / 12108987（等待名单管理）
移植前最终再评估 癌、心血管、衰弱、感染、依从性、心理社会 6 维度复核 34200235（术前心血管叙事综述）/ 30218580（KAS 时代新等待名单管理）
失格（delisting）作为终点 delisting 是既定临床终点（非失败） 33565145（delisting 作为等待名单结局） / 41720194（等待名单死亡指标↔delisting 关联，2026）

判读：再评估 = “入名单评估 + 等待期动态管理 + 移植前最终复核”三段式，等待期动态管理是被长期忽视但 2025-2026 上升为重点的环节。

二、等待名单动态再评估（失格/delisting 前沿）

证据 结论 级别
40484353（KI 2025，多中心前瞻性 delisting 策略） 主动 delisting 策略促进肾移植（对高风险等待者及时失格/重新分层） 多中心前瞻性（高）
41720194（AJT 2026，等待名单死亡指标↔delisting 关联） 新等待名单死亡指标与 delisting 可能性相关 队列
42546904（AJT 2026） delisting 后无移植生存改善→提示数据质量问题（delisting 记录质量需标准） 队列
35703800（JACC 2022，移植中心 delisting/1 年指标变异） 各中心 delisting 与 1 年结局差异大——delisting 是中心质量指标 中心队列
33565145（Clin Transplant 2021，delisting 作为等待名单结局） delisting 应作为正式结局指标纳入等待名单管理 概念
38664156（Human Immunol 2024，高致敏低风险 delisting 策略） 高致敏者（无供体交换offer）可低风险 delisting——选择性 delisting 队列
26762606（AJT 2016，等待名单移除与中心绩效监管） 移除（removal）受中心绩效监管——delisting 是合规管理 政策
22663992（Transplant Proc 2012，临时失格） 临时失格原因/危险因素/结局（inactivation/reactivation 机制） 单中心

判读（2025-2026 前沿，重要）：

  1. delisting 从”被动失格”转向”主动策略”（40484353）——对高风险等待者主动 delisting 再重新分层，可提升整体移植效率；
  2. delisting 是质量指标（35703800）——各中心 delisting 率/1 年结局差异大，delisting 记录质量需标准化（42546904）；
  3. 选择性 delisting（38664156）——高致敏者可按风险分层 delisting，不必”一刀切”。

三、移植前最终再评估 6 大维度

3.1 癌症筛查（最易遗漏的高风险维度）

证据 结论
27218882（Clin Transplant 2016，原肾 RCC 超声监测） 候选者原肾（native kidney）RCC 需常规超声随访——ESRD/透析/ADPKD 原肾癌风险↑
26563384（JASN 2016，ESRD 癌发生率） ESRD 等待期癌（尤其 RCC、宫颈/乳腺）发生率显著
23504812（IJAT 2013，等待名单癌发生/患病，意大利） 等待名单癌检出率——等待期癌筛查应常规
41271370（World J Transplant 2025，供者有癌史） 供者癌史也需再评估（供者侧再评估）
中文（肾脏移植长期健康管理指南） 等待期/移植后癌筛查纳入长期管理

判读：移植前再评估必须复核”原肾癌 + 等待期新发癌”（RCC 超声 + 等待期癌筛查）——移植后免疫抑制会放大未治疗的癌。

3.2 心血管评估（等待名单主要死因）

证据 结论
39980435（Clin Transplant 2024，心肌灌注显像增量预后价值） 心肌灌注显像对等待名单心血管事件有增量预测——纳入再评估
41246800（JAHA 2025，冠脉状态决定移植物/心血管结局） 按冠脉状态分层的移植物 + 心血管结局——冠脉评估是再评估核心
27392506（Am J Cardiol 2016，冠脉造影在候选者心血管评估） 候选者冠脉造影角色
38781937（KBPR 2024，腹部动脉钙定量↔等待名单死亡） 动脉钙化（定量）预测等待名单死亡——再评估变量
30625489（AJN 2019，合并症/衰弱/等待名单死亡全年龄） 合并症 + 衰弱↔等待名单死亡
30795985/33989711（ISCHEMIA-CKD） 等待名单心血管风险与移植时机

判读：心血管是等待名单主要死因——再评估需心肌灌注 + 冠脉状态 + 动脉钙化 + 合并症综合；41246800（冠脉状态分层）+ 39980435（心肌灌注增量）是 2024-2025 新证据。

3.3 衰弱/肌少化（2025-2026 上升为重点）

证据 结论
34656960（Clin Nutr 2021，衰弱/瘦组织流失↔等待名单结局） 衰弱 + 营养不良是等待名单失格/死亡独立预测——纳入再评估
32512039（AJKD 2020，等待名单顶部的候选者体力表现测试） 体力测试（gait/sit-stand）对等待名单顶部候选者有评估价值
30625489（AJN 2019，衰弱全年龄） 衰弱↔等待名单死亡
31781571（Front Nutr 2019，老年衰弱/肌少化） 老年候选者衰弱/肌少化

判读：衰弱/肌少化是”再评估”的新一级变量——不只是”能不能做手术”，而是等待期生存风险 + 移植后早期失格风险；32512039 的体力测试可作为等待名单动态监测工具。

3.4 免疫致敏 + 依从性 + 心理社会

维度 证据 结论
免疫致敏 26054537（JASN 2016，等待名单免疫致敏↔死亡） 高 PRA/DSA↔等待名单死亡↑——再评估需追踪致敏动态
40209457（KI 2025，高致敏 + DSA 西班牙指南） 高致敏者再评估（DSA 分层）
依从性 23923971（Clin Transplant 2013，等待期不活动↔术前/术后结局差） 等待期行为（活动/依从）预测移植后结局
心理社会 32805194/30795985/31033648（卫生素养/身体残障/语言隔离↔结局） 心理社会/卫生素养/语言是再评估维度
28183854（CJASN 2017，语言隔离↔等待名单） 语言隔离影响等待名单进入/结局

判读：免疫致敏动态（DSA）+ 依从性 + 心理社会/卫生素养是”软指标”，但 26054537 证明高致敏↔等待名单死亡，**再评估不能只看”医学适合度”**。

四、特定人群的再评估

人群 再评估要点 证据
老年候选者 衰弱/合并症/手术风险（”how to select”） 25154797（TR 2014）/ 31723590（TD 2019 老年活体供肾应推广）/ UpToDate 老年候选者
糖尿病 1型糖尿病移植策略（心肾/胰肾） 29606260（Nephrol 2018）/ 3146491
ADPKD 术前双肾减容（volume reduction） 29388019（Cardiovasc Intervent Radiol 2018）
HCV 阳性 等待期 HCV 结局（DAA 时代） 30704882（AJKD 2019）/ 41271370 供者癌史
HIV 阳性 HIV 候选者移植希望（2026） 42751191（World J Transplant 2026）
肥胖（减重术后） 减重术→候选者再评估 31668565/28216112（sleeve 术→移植）
儿童等待者 移植前评估（适应证/时机/围手术期/随访） 中文《中国儿童肾脏移植等待者评估与管理指南》（sinomed）

判读：再评估是”分人群”的——老年（衰弱）、ADPKD（减容）、HIV（2026 新希望）、儿童（专门指南）各有再评估要点。

五、临床决策框架（专家综合 + 指南）

“三段式再评估”路径（基于 KDIGO 候选者评估 + 中文长期健康管理指南 + 2025-2026 delisting 证据）：

  1. 入名单前：完整 6 维度（癌、心血管、衰弱、感染、依从性、心理社会）——建立”再评估基线”；
  2. 等待名单动态再评估（2025-2026 重点）：
    • 定期（如 6-12 月）复核：癌（原肾 RCC 超声 27218882）+ 心血管（心肌灌注/冠脉 39980435/41246800）+ 衰弱（体力测试 32512039）+ 致敏（DSA 26054537）+ 依从性（23923971）；
    • 主动 delisting 策略（40484353）：对高风险等待者主动失格再重新分层，非被动等待；
    • 选择性 delisting（38664156）：高致敏无 offer 者可低风险 delisting；
  3. 移植前最终再评估：术前 6 维度全复核（34200235 心血管叙事综述 + KDIGO），**”移植日关口”**；
  4. delisting 作为既定终点（33565145/41720194）：delisting 纳入等待名单管理 KPI，记录质量需标准化（42546904）。

六、判读陷阱

陷阱 判读
“候选者评估是入名单时一次性的” ✗ 错误——是全程动态（入名单 + 等待期 + 移植前最终）
“delisting = 失败” ✗ 错误——delisting 是既定临床终点/质量指标（33565145/35703800），主动 delisting 可提升移植效率（40484353）
“再评估只看医学适合度” ✗ 不全——免疫致敏动态（26054537）+ 依从性（23923971）+ 心理社会/卫生素养/语言（31033648/28183854）是软但关键的再评估维度
“原肾癌不重要” ✗ 错误——ESRD/透析/ADPKD 原肾 RCC 需常规超声（27218882），移植后免疫抑制放大未治疗癌
“衰弱是主观评价” ✗ 有客观工具——体力测试（gait/sit-stand，32512039）+ 瘦组织流失（34656960）可作为等待名单动态监测

七、研究空白（后续追踪）

空白 级别 说明
delisting 的量化决策工具/风险模型 ⭐⭐⭐ 40484353 前瞻性策略 + 41720194 死亡指标，但无统一 delisting 风险评分
衰弱/肌少化纳入候选者再评估的前瞻性验证 ⭐⭐ 34656960/32512039 观察性，衰弱作为再评估变量的前瞻性 cohort 缺失
等待名单动态再评估的”最佳频率” ⭐⭐ 6 月 vs 12 月 vs 移植前——无 RCT 界定
高致敏选择性 delisting（38664156）的长期移植物结局 ⭐⭐ 仅低风险短期，长期结局未定
delisting 记录质量/数据标准的国际统一 ⭐ 42546904 提示数据质量问题，无统一 delisting 数据标准
HIV 候选者（42751191）长期再评估 ⭐ 2026 早期”希望”，长期再评估路径未定

八、检索与判读说明

  1. PubMed 16+10 式（206+61 命中去重）；**”候选者再评估”作为主题命中偏散（多为等待名单管理/评估/delisting 各向）——核心 = 流程/指南导向**，无单一”再评估 RCT”
  2. 最高等级 = KDIGO 候选者评估指南（国际）+ 40484353（KI 2025 多中心前瞻性 delisting）+ 41720194/35703800（等待名单死亡/delisting 质量指标）
  3. 2025-2026 前沿 = 主动 delisting 策略 + 衰弱/肌少化作为再评估变量 + delisting 记录质量标准化
  4. 中文：《中国儿童肾脏移植等待者评估与管理临床诊疗指南》（sinomed）+《肾脏移植长期健康管理指南》（张伟杰/邹志宇等，中华）+ KDIGO 候选者评估指南（medsci）经 Tavily 核实、未 CNKI/万方原文核对
  5. **全部”再评估”证据无 RCT 界定”最佳再评估频率/工具”**；delisting 策略（40484353）是最接近”主动再评估”的前瞻性证据
